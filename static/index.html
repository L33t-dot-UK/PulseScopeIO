Recording formats and threshold help

Expected CSV: header row with columns named A+/A−, B+/B−, Z+/Z− (or A, −A, B, −B, Z, −Z), plus an optional time column (for example Time_s, time, timestamp, or t). Sample index is used if no time column is selected. Low/high thresholds use hysteresis: values at or below low become 0, values at or above high become 1, and values between them keep the previous state. Set both thresholds to the same value for a single switching level. The non-thresholded raw plot connects the original numeric values; pulse measurements continue to use thresholds. How replay works

Solid green shows pulse-counted azimuth; dim dotted green shows expected azimuth from Z timing, or estimated normal pulse timing when no complete Z interval exists. The no-Z estimate is not an independent missing-pulse measurement. A edges drive rotation when available; otherwise B edges are used. The other phase determines direction; a single phase assumes clockwise. Z rising edges always reset azimuth to North. With no complete Z interval, set Pulses/rev for calibration (default 8192). With RPM entered, each Z-to-Z revolution takes exactly 60/RPM seconds regardless of sample count. Replay speed scales both lines from 0.1× (10%) to 1.0× (100%). Playback loops continuously at the end of the recording until paused. Follow replay when zoomed pans both waveform diagrams with the green cursor, preserving the selected time-window width. Pause freezes the view; clear the checkbox to inspect a fixed interval during playback.

Pulse measurements

Duty cycle is not calculated for Z or −Z index pulses. Their high/low widths, period and frequency remain available; duty tolerance checks apply to A/−A and B/−B only.

How measurements are calculated

Analysis covers the selected measurement scope; the default covers the entire file. PDF reports cover the entire file. Logic timing has sample resolution. Analog rise/fall times use the selected online crossing-pairing or local resolved-ramp estimator. Plots use extrema envelopes when zoomed out.

Pulses/rev uses the available A or B channel between consecutive Z rising edges; −Z is ignored as a revolution reference. Frequency is shown in Hz when a time base is available, or per sample when it is not. Metrics that need missing channels are marked unavailable. For each A/B/Z channel independently, calculations use reconstructed RS422 Rx data when both sides of its differential pair are present, and fall back to direct channel data otherwise. Rise/fall time uses differential input voltage where a pair is available; the six-channel plot remains raw.

Noise & short pulse candidates

Raw, unsmoothed crossings use the selected thresholds. A candidate is an interior high or low run shorter than 10% of its channel’s mean analysed high or low width. End fragments are excluded. Plateau RMS variation includes noise, ramps and drift; it is not a bandwidth-limited noise measurement.

How should the third capture be used?

Z pulses align the revolutions. Independent captures can still differ in A/B timing within a revolution, even after their sample rates have been scaled.

Check alignment only Recommended default

Preserve the Z-aligned B timing. Use the independent A/−A/B/−B capture to report the relative A/B phase difference without changing the merged waveform.

Refine B timing

Use a coherent third capture as a phase reference and resample B timing relative to A. Original source files are kept, but the merged B waveforms, measurements and downloaded CSV change. Refinement keeps the verified complete-Z span; partial endpoints may be trimmed.

The adjusted result is not an independent proof of alignment: it has been fitted to the reference. Refinement cannot establish absolute revolution identity without Z.
